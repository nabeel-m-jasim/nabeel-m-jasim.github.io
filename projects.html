Space & Fundamental Physics

Astrobee — International Space Station (ISS)

Collaborated with NASA and MIT under MBRSC's organization to program Astrobee, a robotic system operating aboard the ISS. Developed algorithms tested in a zero-gravity environment using the Bumble Astrobee unit. Participated in a live session with astronaut Sultan Al Neyadi, observing our algorithms operating in space.

Skills: C Programming, Machine Learning Algorithms

Kibo Robot Programming Challenge

Programmed JAXA's Kibo robotic system aboard the International Space Station using Android Studio. Contributed to research in autonomous robotics and space automation.

Skills: Python Programming

Asian Try Zero-G 2025

Investigated how magnetic forces influence pendulum motion under microgravity conditions. Explored possible applications in spacecraft stabilization and control systems.

Advanced Materials & Space Applications

MOF-Based Radiation Shield for Mars Missions

Designed a metal-organic framework (MOF)-based radiation shielding concept for long-duration human space exploration. Investigated advanced materials approaches for astronaut protection against radiation exposure.

Nicotine Reduction for Electronic Vapes

Developed an engineering and materials-based approach to reduce nicotine delivery while maintaining user experience. Explored solutions aimed at reducing nicotine dependency.
